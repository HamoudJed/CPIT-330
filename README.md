# 🕋 منصة الإرشاد الذكي — Smart Guidance Platform

> دليلك الرقمي التفاعلي في رحلة الحج والعمرة  
> Your interactive digital guide for Hajj & Umrah

---

## 📌 نظرة عامة | Overview

**منصة الإرشاد الذكي** هي تطبيق ويب تفاعلي يُرشد الحاج والمعتمر خلال مناسكه خطوة بخطوة، مع عدادات تفاعلية وأدعية مخصصة لكل موقف.

**Smart Guidance Platform** is an interactive web app that guides pilgrims through Hajj and Umrah rituals step by step, with interactive counters and contextual supplications.

---

## ✨ المميزات | Features

### العمرة | Umrah
- ✅ إرشاد تفاعلي لجميع مناسك العمرة (الإحرام، الطواف، السعي، الحلق/التقصير)
- ✅ عداد الطواف التفاعلي (7 أشواط) مع تتبع التقدم
- ✅ عداد السعي التفاعلي (7 أشواط) مع تتبع التقدم
- ✅ أدعية مقترحة لكل شوط
- ✅ شرح السنن والمستحبات لكل خطوة
- ✅ إشعارات لحظية عند إتمام كل شوط

### الحج | Hajj
- 🔜 قيد التطوير — يوم التروية، عرفة، مزدلفة، منى، أيام التشريق، طواف الوداع

### عام | General
- 🌍 دعم اللغتين العربية والإنجليزية
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- ⚡ تطبيق ويب بدون خادم خلفي (Pure Frontend)

## 🚀 طريقة التشغيل | Getting Started

لا يحتاج المشروع إلى تثبيت أي شيء. فقط:

```bash
# 1. استنسخ المشروع
git clone https://github.com/HamoudJed/CPIT-330.git

# 2. ادخل على المجلد
cd CPIT-330

# 3. افتح الملف الرئيسي في المتصفح
open index.html
```

أو افتح `index.html` مباشرة بالنقر عليه في مستكشف الملفات.
